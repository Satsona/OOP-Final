# Top-Down Arena Shooter – README (Short)

## 🎮 Controls

* **WASD** – Move player
* **Mouse** – Aim
* **Left Click** – Shoot

---

## 🏆 Win Conditions

The player wins if **either** of the following is achieved:

* Survive for **120 seconds**
* Reach **300 score**

Winning loads the **Win Scene (WScene)**.

---

## ☠ Lose Condition

* If the player’s health reaches **0**, the player dies
* Player health reduces to 0 in contact with enemies
* The game loads the **Lose Scene (LScene)**
